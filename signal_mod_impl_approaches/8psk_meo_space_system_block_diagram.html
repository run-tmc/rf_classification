8-PSK Advantages for Space Communications
Spectral Efficiency: 3 bits/symbol (1.5x QPSK, 3x BPSK bandwidth efficiency) | Constant Envelope: All symbols lie on unit circle, ideal for nonlinear SSPA/TWTA | Higher Throughput: 50% more data rate than QPSK in same bandwidth | Heritage: DVB-S2 (adaptive coding), Satellite backhaul, Deep space (high SNR links)
IF-Based Simulation Architecture (200 MHz IF)
Why IF-Based: Direct 26 GHz carrier simulation would require >52 GHz sample rate (Nyquist) | TX Chain: Baseband -> IF (200 MHz) upconversion via quadrature modulation | Channel Model: Applies 26 GHz carrier effects (Doppler, FSPL, phase noise) to IF signal | RX Chain: IF (200 MHz) -> Baseband downconversion with LPF | Sample Rate: 1 GHz (100 samples/symbol at 10 MSym/s) for accurate RF behavior
8-PSK Design Considerations
Higher Eb/N0 Required: ~3.5 dB penalty vs QPSK for same BER (14 dB vs 10.5 dB @ BER=10^-6) | Phase Noise Sensitivity: Smaller phase separation (45 deg vs 90 deg) requires tighter phase noise spec (0.005 rad RMS) | Use Case: Best for high SNR links where bandwidth is limited but power is available

"""
8-PSK MEO Inter-Satellite Link (ISL) System Implementation
Space-based signal processing chain for Medium Earth Orbit communications
8-ary Phase Shift Keying with LDPC FEC

RF System Architecture:
- Carrier Frequency: 26 GHz (Ka-band)
- Sample Rate: 1 GHz (supports 200 MHz IF with 5x oversampling)
- Intermediate Frequency: 200 MHz
- Symbol Rate: 10 MSym/s (30 Mbps with 8-PSK)

The simulation uses IF-based representation where:
- Transmitter: Baseband -> IF (200 MHz) upconversion
- Channel: Applies 26 GHz carrier effects (Doppler, FSPL, phase noise)
- Receiver: IF (200 MHz) -> Baseband downconversion
"""

import numpy as np
from scipy import signal
from scipy.signal import butter, filtfilt, hilbert
from scipy.constants import c, k  # speed of light, Boltzmann

# ============== RF SYSTEM PARAMETERS ==============
CARRIER_FREQ = 26e9             # 26 GHz Ka-band
SYMBOL_RATE = 10e6              # 10 MSym/s
BITS_PER_SYMBOL = 3             # 8-PSK: 3 bits per symbol
SAMPLES_PER_SYMBOL = 100        # Oversampling for RF simulation
SAMPLE_RATE = SYMBOL_RATE * SAMPLES_PER_SYMBOL  # 1 GHz
IF_FREQUENCY = 200e6            # 200 MHz IF
ROLLOFF = 0.25                  # RRC roll-off factor
FILTER_SPAN = 12                 # symbols

# ============== RF UP/DOWN CONVERSION ==============

def rf_upconvert(baseband_signal, sample_rate=SAMPLE_RATE, if_freq=IF_FREQUENCY):
    """Up-convert complex baseband signal to IF (200 MHz)

    Performs quadrature modulation:
    RF(t) = I(t)*cos(2*pi*f_IF*t) - Q(t)*sin(2*pi*f_IF*t)
    """
    t = np.arange(len(baseband_signal)) / sample_rate
    i_component = np.real(baseband_signal)
    q_component = np.imag(baseband_signal)
    cos_carrier = np.cos(2 * np.pi * if_freq * t)
    sin_carrier = np.sin(2 * np.pi * if_freq * t)
    rf_signal = i_component * cos_carrier - q_component * sin_carrier
    return rf_signal

def rf_downconvert(rf_signal, sample_rate=SAMPLE_RATE, if_freq=IF_FREQUENCY):
    """Down-convert IF signal (200 MHz) to complex baseband

    I(t) = LPF{RF(t) * 2*cos(2*pi*f_IF*t)}
    Q(t) = LPF{RF(t) * -2*sin(2*pi*f_IF*t)}
    """
    t = np.arange(len(rf_signal)) / sample_rate
    cos_carrier = 2 * np.cos(2 * np.pi * if_freq * t)
    sin_carrier = -2 * np.sin(2 * np.pi * if_freq * t)
    i_mixed = rf_signal * cos_carrier
    q_mixed = rf_signal * sin_carrier
    # Low-pass filter to remove double-frequency component
    nyq = sample_rate / 2
    lpf_cutoff = SYMBOL_RATE * (1 + ROLLOFF) * 1.1
    b, a = butter(5, lpf_cutoff / nyq, btype='low')
    i_baseband = filtfilt(b, a, i_mixed)
    q_baseband = filtfilt(b, a, q_mixed)
    return i_baseband + 1j * q_baseband

# ============== TRANSMITTER ==============

def meo_8psk_transmitter(data_bits):
    """Complete MEO 8-PSK satellite transmitter chain

    Signal processing flow:
    1. LDPC encoding (rate 3/4)
    2. Block interleaving for burst error protection
    3. Scrambling with LFSR sequence
    4. 8-PSK modulation (Gray-coded)
    5. Upsampling and RRC pulse shaping
    6. RF up-conversion to IF (200 MHz)

    Returns: rf_signal, baseband_signal, symbols, rrc, tx_params
    """
    encoded = ldpc_encode(data_bits, code_rate=0.75)
    interleaved = block_interleave(encoded)
    scrambled = scramble(interleaved)
    symbols = psk8_modulate(scrambled)
    # Upsampling and pulse shaping
    upsampled = np.zeros(len(symbols) * SAMPLES_PER_SYMBOL, dtype=complex)
    upsampled[::SAMPLES_PER_SYMBOL] = symbols
    rrc = rrc_filter(FILTER_SPAN * SAMPLES_PER_SYMBOL + 1, ROLLOFF, SAMPLES_PER_SYMBOL)
    shaped = np.convolve(upsampled, rrc, mode='same')
    baseband_signal = shaped.copy()
    rf_signal = rf_upconvert(shaped)
    return rf_signal, baseband_signal, symbols, rrc, tx_params

# ============== RECEIVER ==============

def meo_8psk_receiver(rf_signal, rrc, num_symbols, num_info_bits, scrambled_len, doppler_hz=0):
    """Complete MEO 8-PSK satellite receiver chain

    Signal processing flow:
    1. RF down-conversion from IF to complex baseband
    2. Low-pass filtering to remove out-of-band noise
    3. Doppler compensation
    4. Carrier recovery (8th power PLL) - bypassed if Doppler known
    5. Matched filtering (RRC)
    6. Symbol timing and downsampling
    7. 8-PSK demodulation
    8. Descrambling, de-interleaving, LDPC decoding

    Returns: decoded_bits, rx_symbols, intermediate_signals
    """
    # RF down-conversion from IF (200 MHz) to complex baseband
    baseband_after_downconv = rf_downconvert(rf_signal)
    # Low-pass filter
    nyq = SAMPLE_RATE / 2
    b, a = butter(5, SYMBOL_RATE * (1 + ROLLOFF) / nyq, btype='low')
    baseband_after_lpf = filtfilt(b, a, baseband_after_downconv)
    # Doppler compensation
